# بازی ماشین با کنترل دست

یک بازی دوبعدی با نمای «چشمِ راننده» و پرسپکتیو شبه‌سه‌بعدی با Python که در آن ماشین باید از موانع جاده عبور کند. موانع از خط افق در دوردست ظاهر می‌شوند و با نزدیک شدن، بزرگ‌تر می‌شوند — درست همان‌طور که راننده از جلو آن‌ها را می‌بیند — و ماشین در لحظه آخر از جلوی آن‌ها جاخالی می‌دهد. جای دست شما در تصویر دوربین، ماشین را به چپ و راست هدایت می‌کند.

## اجرا

برای اجرای کامل با دوربین، Python 3.12 پیشنهاد می‌شود. در Python 3.14، به‌جای pygame معمولی از pygame-ce استفاده شده است تا نصب wheel آماده روی ویندوز انجام شود؛ اگر MediaPipe برای نسخهٔ Python شما wheel نداشت، از Python 3.12 استفاده کنید:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

دوربین هنگام اجرای بازی باز می‌شود و تصویر کوچک آن در گوشهٔ پنجره نمایش داده می‌شود. کف دست را جلوی دوربین به چپ و راست حرکت دهید. تصویر دوربین به‌صورت آینه‌ای است، بنابراین حرکت دست به چپ، ماشین را به چپ می‌برد.

## کنترل‌ها

- حرکت دست به چپ و راست: هدایت ماشین
- `←` و `→` یا `A` و `D`: کنترل جایگزین با صفحه‌کلید
- `R`: شروع دوباره پس از تصادف
- `M`: قطع/وصل صدای بازی
- `Q` یا `Esc`: خروج

اگر دوربین وجود نداشته باشد یا باز نشود، بازی به‌صورت خودکار با صفحه‌کلید قابل بازی است. برای دسترسی دوربین، مجوز آن را در سیستم‌عامل تأیید کنید.

## سیستم جان (سه قلب)

ماشین شما سه قلب دارد که در بالای صفحه نمایش داده می‌شوند. با هر برخورد یک قلب کم می‌شود و حدود ۱.۶ ثانیه بی‌آسیبی موقت (همراه با چشمک زدن ماشین) دریافت می‌کنید تا فرصت فرار داشته باشید. فقط با از دست دادن هر سه قلب، عبارت **GAME OVER** نمایش داده می‌شود و بازی پایان می‌یابد.

## صدا

همه جلوه‌های صوتی بازی (صدای موتور بسته به سرعت، برداشتن سکه، برخورد، تصادف نهایی و آهنگ پایان بازی) به‌صورت برنامه‌نویسی و بدون هیچ فایل صوتی خارجی ساخته می‌شوند، پس نیازی به دانلود فایل اضافه نیست. اگر کارت صدا در دسترس نباشد، بازی بدون خطا و بی‌صدا اجرا می‌شود. با کلید `M` می‌توانید صدا را در هر لحظه قطع یا وصل کنید.

## نمایش صحیح متن فارسی

برای نمایش درست حروف فارسی (اتصال حروف و ترتیب راست‌به‌چپ) در pygame، دو کتابخانهٔ `arabic-reshaper` و `python-bidi` به `requirements.txt` اضافه شده‌اند و قبل از نصب کامل، این جملات ممکن است به‌هم‌ریخته یا بدون اتصال حروف نمایش داده شوند. اگر بعد از `pip install -r requirements.txt` باز هم مشکلی دیدید، مطمئن شوید نسخهٔ فونت Tahoma/Arial روی سیستم شما نصب است.

## رفع خطای نصب pygame در Python 3.14

دستور `pip install pygame` ممکن است در Python 3.14 به‌جای wheel، وارد مرحلهٔ ساخت از سورس شود و خطای SDL یا timeout بدهد. این پروژه از `pygame-ce` استفاده می‌کند، اما در کد همچنان همان `import pygame` صحیح است. اگر قبلاً نصب ناموفق انجام داده‌اید، این دستورات را اجرا کنید:

```powershell
python -m pip uninstall pygame -y
python -m pip install --only-binary=:all: pygame-ce
python -m pip install -r requirements.txt
```

اگر `mediapipe` روی Python 3.14 برای سیستم شما wheel نداشت، Python 3.12 را نصب کنید و سپس دستورات نصب را با همان نسخه اجرا کنید:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```
